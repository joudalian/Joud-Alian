# موقع العهد للديكور والأدوات الصحية

موقع تعريفي من صفحة واحدة، عربي بالكامل (RTL)، كل الطلبات بتروح على **واتساب** مباشرة.
مبني HTML/CSS/JS صِرف — بدون أي إطار عمل، بدون خطوة بناء، وبدون خادم.

---

## ⚡ أول إشي: حط رقم الواتساب

افتح `assets/js/config.js` وعدّل السطر:

```js
whatsapp: "970599123456",   // ← رقمك بالصيغة الدولية، بدون + وبدون مسافات
phoneDisplay: "+970 59 912 3456",
```

نفس الملف فيه كمان: عنوان المعرض، أوقات الدوام، رابط خرائط جوجل، وروابط
إنستغرام/فيسبوك/تيك توك (اتركها `""` لتختفي من الموقع).

> **هذا الملف الوحيد اللي لازم تعدّله.** باقي الموقع بياخد المعلومات منه تلقائياً.

---

## 🚀 كيف تشغّل الموقع

### محلياً (للتجربة)
```bash
cd site
python3 -m http.server 8000
# افتح: http://localhost:8000
```

### على الإنترنت
الموقع ملفات ثابتة — ارفع مجلد `site/` كما هو على أي استضافة:

| الخيار | كيف |
|---|---|
| **Netlify** | اسحب مجلد `site` على netlify.com/drop |
| **Vercel** | `vercel deploy` من داخل المجلد |
| **GitHub Pages** | فعّل Pages من إعدادات المستودع واختر مجلد `site` |
| **استضافة عادية (cPanel)** | ارفع محتويات المجلد على `public_html` |


## 🖼️ تبديل الصور

كل صورة جوّا `assets/img/`. بدّلها بنفس الاسم وبنفس النِسبة، والموقع بياخدها فوراً:

| الملف | وين بتظهر | النسبة المفضّلة |
|---|---|---|
| `hero.webp` | الخلفية الرئيسية | عريضة 16:9 |
| `showroom.webp` | قسم "من نحن" | عريضة 16:9 |
| `vanity.webp` | مغاسل وخزائن | طولية 4:5 |
| `faucet.webp` | خلاطات وأدوات صحية | مربعة 1:1 |
| `shower.webp` | كبائن ودشات | طولية 4:5 |
| `tiles.webp` | سيراميك وبورسلان | طولية 4:5 |
| `gypsum.webp` | ديكورات جدران | طولية 4:5 |
| `accessories.webp` | إكسسوارات | طولية 4:5 |

نصيحة: خلّي عرض الصورة بحدود 1600px للخلفية و800px للأقسام، وبصيغة WebP
عشان الموقع يضل سريع.

## ✏️ تعديل النصوص

كل النصوص مكتوبة عربي صريح جوّا `index.html` — افتحه بأي محرّر، دوّر على الجملة،
وبدّلها. الأقسام مفصولة بتعليقات واضحة:

```html
<!-- ═══ الأقسام ═══ -->
<!-- ═══ المعرض ═══ -->
<!-- ═══ آراء العملاء ═══ -->
```

لإضافة قسم جديد للأقسام الستة، انسخ بلوك `<article class="cat">` كامل وبدّل
الصورة والعنوان والنص ورسالة الواتساب اللي بـ `data-wa-msg`.

---

## 💬 كيف بيشتغل الطلب

- كل زر واتساب بالموقع عنده `data-wa-msg` — هاي الرسالة اللي بتنفتح جاهزة عند الزبون.
- نموذج "اطلب الآن" بيجمع الاسم والمنطقة والقسم والتفاصيل، وبيبني منهم رسالة
  منسّقة وبيفتحها بواتساب. الزبون بس بيضغط إرسال.
- ما في قاعدة بيانات ولا دفع أونلاين ولا تسجيل — كل شي بيصير بالمحادثة.

## 🎨 الألوان والخطوط

الألوان كلها متغيّرات بأول `styles.css` تحت `:root` — غيّر القيمة مرّة وبتتغيّر
بكل الموقع:

```css
--ink:   #14100D;   /* الأسود الدافئ */
--bone:  #F8F4ED;   /* الخلفية الفاتحة */
--brass: #B08B4F;   /* النحاسي */
```

الخطوط: **Reem Kufi** للعناوين (بيناسب الخط الكوفي بالشعار) و**Tajawal** للنصوص،
الاثنين من Google Fonts.
