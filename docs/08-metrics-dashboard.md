## 3. جدول التشخيص — العَرَض ← السبب ← الإجراء

| العَرَض | السبب الأرجح | الإجراء الفوري |
|---|---|---|
| عروض < 20/أسبوع | التنفيذ يبتلع البيع | أعد ترتيب اليوم: البيع أولاً. اضبط منبهاً |
| عروض كثيرة، فوز صفر بعد 40 عرضاً | نص العرض عام / لا تخصيص | أعد كتابة العرض. افتح كل واحد بملاحظة عن متجره هو |
| محادثات تبدأ ثم تتوقف | فجوة ثقة (R6) | أرفق فيديو العرض + الضمان في الرسالة **الأولى**، لا الثالثة |
| «السعر غالي» متكررة | تبيع تقنية لا نتيجة | اعرض حسبة الاسترجاع (الفصل 03/القسم 3) قبل ذكر السعر |
| زمن L1 لا ينخفض | لا تبني قالباً | 🚨 **P3** — أوقف البيع يومين |
| متعاقَد جيد، محصَّل منخفض | فجوة التحويل أو حد الـ250$ | طبيعي قبل اليوم 25. بعده: راجع القناة |
| عملاء يطلبون إضافات باستمرار | نطاق غير مكتوب | نطاق مكتوب في كل عقد + مراجعتان كحد أقصى |
| تخطّي أيام متتالية | إرهاق (R11) | يوم راحة مُخطط. 2.5 ساعة سقف لا يُتجاوز |
| صفقات L0 كثيرة، L1 صفر | لا تعرض الترقية | اعرض L1 في **متابعة اليوم 7** لكل عميل L0. بلا استثناء |

## 5. محفزات تغيير المسار (Pivot)

| المحفّز | التوقيت | التحوّل |
|---|---|---|
| متاجر سلة/زد لا تستجيب، لكن **الشركات الخدمية** تستجيب | اليوم 20+ | حوّل الاستهداف: عيادات، مكاتب عقار، صالونات. **نفس القوالب** بنصوص مختلفة |
| العملاء يطلبون **بناء متاجر** لا أتمتة | اليوم 20+ | اقبل — النموذج (ج) كان ثاني أعلى درجة (7.75). ادخل به وبِع الأتمتة كترقية |
| وكالة واحدة تريد **حجماً كبيراً** | أي وقت | **حوّل 70% من الجهد إليها.** هذه أعلى رافعة في الخطة كلها |
| القنوات العربية أصعب من المتوقع | اليوم 25+ | جرّب Upwork بعرض **مُنتَج** (لا ساعات) — القناة أصعب لكن غير مستحيلة |
| الاشتراكات (R) تُباع أسهل من المشاريع | اليوم 30+ | اقلب النموذج: L1 بسعر رمزي 299$ + اشتراك إلزامي 349$/شهر. **MRR أثمن من الدفعة الواحدة** |

> **الفرق بين التغيير والتشتت:** التغيير يحتفظ بالأصل (القوالب، القناة، التموضع) ويبدّل متغيراً واحداً. التشتت يبدأ من الصفر. **لا تبدأ من الصفر بعد اليوم 20 مهما حدث.**

## 6. نقاط الإيقاف الحقيقية

توقّف فقط في هذه الحالات الثلاث:

```
1. فشل قناة الدفع في اليوم 3          →  توقّف · P1 · لم تخسر إلا 25$
2. صفر صفقات في اليوم 32 بعد 120 عرضاً →  النموذج لا يعمل لك. أوقف الإنفاق وأعد التقييم
3. ظرف قاهر يمنع الاستمرارية           →  أوقف قبول العملاء، سلّم ما التزمت به، وجمّد
```

**وما ليس نقطة إيقاف:**

| ❌ ليس سبباً للتوقف | لماذا |
|---|---|
| عدم بلوغ 5,000$ | احتمال ذلك 20-25% أصلاً. 3,000$ + أصل عامل = **نجاح** |
| رفض عميل | معدل الفوز 8% يعني **92% رفضاً**. الرفض هو الوضع الطبيعي، لا الإشارة |
| بطء الأسبوعين الأولين | مُصمَّم هكذا. الإيراد صفر حتى اليوم 12 في الخطة نفسها |
| عطل تقني | مُخطَّط له في P5 |
| منافس أرخص | لا تنافس على السعر. نافس على النتيجة والضمان |

## 7. تعريف النجاح — ثلاثة مستويات

```
┌────────────────────────────────────────────────────────────┐
│  🥉 الحد الأدنى  (احتمال ~70%)                             │
│     ≥ 2,000$ محصَّل · 3 تقييمات · قالب ناضج · قناة دفع     │
│     → الأساس جاهز. الشهر القادم أسهل بمرتين.               │
├────────────────────────────────────────────────────────────┤
│  🥈 النجاح الفعلي  (احتمال ~35%)                           │
│     ≥ 3,400$ محصَّل · عميل اشتراك · شراكة وكالة            │
│     → مشروع قائم يولّد إيراداً متكرراً.                     │
├────────────────────────────────────────────────────────────┤
│  🥇 الهدف المعلن  (احتمال ~20-25%)                         │
│     ≥ 5,000$ محصَّل خلال 50 يوماً                          │
│     → 10 أضعاف رأس المال. ممكن، على الحافة.                │
└────────────────────────────────────────────────────────────┘
```

> **ثلاثتها تتحقق بنفس الأفعال اليومية.** الفرق بينها ليس في الجهد، بل في معدل الفوز والسعر وسرعة القالب — وكلها تتحسن بالتكرار.
>
> **لا تُدر يومك بحثاً عن 5,000$. أدره بحثاً عن: 4 عروض، وقالب أسرع، وعميل يرى نتيجة.** الرقم نتيجة، لا هدف تشغيلي.
