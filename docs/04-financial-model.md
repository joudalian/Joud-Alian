# 04 — النموذج المالي

## 1. سقف الطاقة الاستيعابية — الرقم الذي يحكم كل شيء

قبل أي سيناريو، يجب معرفة **أقصى ما يمكن أن ينتجه وقتك نظرياً**. الطلب ليس القيد — وقتك هو القيد.

### ميزانية الوقت الكاملة

```
2.5 ساعة/يوم × 50 يوماً = 125 ساعة إجمالاً
```

| المرحلة | التوزيع | الساعات |
|---|---|---|
| **المرحلة 0** (الأيام 1-7) | تحقق الدفع + بنية + بناء القالب — 100% من الوقت | **17.5** |
| **الأيام 8-50** (43 يوماً) | بيع: 45 د/يوم | 32.25 |
| | تنفيذ: 90 د/يوم | **64.5** |
| | أصول ومحتوى: 15 د/يوم | 10.75 |
| | **الإجمالي** | **125.0** |

### السقف النظري المطلق

```
طاقة التنفيذ المتاحة          = 64.5 ساعة
زمن تنفيذ L1 بعد نضج القالب   = 5 ساعات
                              ────────────
الحد الأقصى النظري            = 12 وحدة L1
12 × 719$ (صافي مباشر)        = 8,628$
```

```
┌──────────────────────────────────────────────────────────┐
│  الهدف 5,000$  =  58% من السقف النظري المطلق             │
│                                                          │
│  أي أنك تحتاج كفاءة بيع وتنفيذ تبلغ 58%                  │
│  لا 100% — لكن لا 30% أيضاً.                             │
│  هذا بالضبط معنى "ممكن، لكن على الحافة".                 │
└──────────────────────────────────────────────────────────┘
```

> **الاستنتاج الحاسم:** لا يمكنك الوصول للهدف بزيادة عدد الصفقات وحدها — **السقف يحدّه زمن التنفيذ، لا الطلب.** لذلك تحسين القالب (خفض 5 ساعات إلى 4) يساوي في الأثر إغلاق صفقتين إضافيتين.

### 🔵 السيناريو الاستثنائي — احتمال 15%

يتحقق إذا نجحت **شراكة وكالة** وجلبت 3 مشاريع white-label بـ 700$ صافية.

```
الأساس المستهدف            5,586$
+ 3 × 700$ (شراكة)         2,100$
                          ─────────
المحصَّل المتوقع            7,686$
```

> **⚠️ قيد صارم:** هذا السيناريو يتطلب **69.5 ساعة تنفيذ** مقابل **64.5 متاحة** = **108% من الطاقة**.
> لا يتحقق إلا بأحد أمرين: رفع الوقت إلى **3.5 ساعة/يوم**، أو خفض زمن تنفيذ L1 إلى **4 ساعات**.
> **لا تقبل عملاً لا تستطيع تنفيذه.** قبول صفقة وتأخير تسليمها = تقييم سيئ = انهيار القناة كلها.

| السيناريو | المحصَّل | الاحتمال | القيمة المرجّحة |
|---|---|---|---|
| متعثّر | 1,144$ | 30% | 343$ |

| مستهدف | 5,586$ | 20% | 1,117$ |
| استثنائي | 7,686$ | 15% | 1,153$ |
| | | | **القيمة المتوقعة: 3,816$** |

```
احتمال تحصيل ≥ 5,000$        =  35%  (المستهدف + الاستثنائي)
احتمال تحصيل ≥ 2,000$        =  70%
احتمال استرداد الـ500$       =  ~88%

```

> **ملاحظة على الرقم 35%:** السيناريو الاستثنائي مشروط بتجاوز الطاقة الاستيعابية. إذا التزمت بـ 2.5 ساعة يومياً بصرامة، فالاحتمال العملي لبلوغ 5,000$ **≈ 20-25%**. الرقم 35% يفترض استعدادك لرفع الوقت عند ظهور فرصة الشراكة.

## 5. تحليل الحساسية — أي متغير يقتل الخطة؟

| المتغير | التغيّر | الأثر على المحصَّل | الخطورة |
|---|---|---|---|
| **زمن تنفيذ L1** | 5 س → **10 س** | الطاقة تنخفض للنصف → السقف **4,300$** → **الهدف مستحيل** | 🔴 **الأعلى** |
| **معدل الفوز** | 8% → 4% | الصفقات تنخفض للنصف → **~1,700$** | 🔴 عالية |
| **سعر L1** | 749$ → 999$ | +33% إيراد بنفس الساعات → **~4,600$** | 🟢 **أقوى رافعة إيجابية** |
| **سعر L1** | 749$ → 500$ | يلزم 12 صفقة بدل 8 → **يتجاوز الطاقة** → الهدف مستحيل | 🔴 عالية |
| **فجوة التحويل** | 10 يوم → 14 يوم | موعد الإغلاق ينتقل لليوم 36 → **−700$** | 🟡 متوسطة |
| **الوقت اليومي** | 2.5 س → 3.5 س | الطاقة +40% → **~4,800$** | 🟢 عالية |
| **معدل الترقية L0→L1** | 45% → 20% | −2 صفقة → **−1,300$** | 🟡 متوسطة |
| **فشل قناة الدفع** | — | **صفر** | ⚫ قاتلة (تُحسم اليوم 3) |

### الاستنتاجات العملية من الحساسية

```
1. زمن التنفيذ  >  عدد الصفقات   ←  استثمر في القالب قبل البيع
2. السعر        >  الحجم         ←  ارفع السعر، لا تزد العملاء
3. 45 دقيقة بيع يومياً غير قابلة للتفاوض  ←  معدل الفوز هو المحرك الثاني
```

> **التوصية الصادرة عن هذا التحليل:** ابدأ L1 بـ **749$**، وارفعه إلى **999$** فور الحصول على **3 تقييمات إيجابية** (متوقع ~اليوم 26).
> رفع السعر هو **أرخص طريقة لزيادة الإيراد**، لأنه لا يكلّف ساعة واحدة إضافية.

## 6. ما بعد اليوم 50 — القيمة الحقيقية

| الأصل المتبقي (السيناريو الأساسي) | القيمة |
|---|---|
| 8 قوالب أتمتة جاهزة ومُختبَرة | تنفيذ 4-5 ساعات بدل 12 |
| 4-6 تقييمات موثّقة على مستقل | معدل فوز 12-15% بدل 4% |
| 1-3 عملاء على اشتراك شهري | **249 - 747$/شهر متكرر** |
| علاقة مع 1-2 وكالة | تدفق عملاء بلا بيع |
| قناة دفع مُختبَرة وعاملة | القيد الأصعب — محلول نهائياً |

```
الإيراد الشهري المتوقع في الشهر الثالث:  2,500 - 4,000$
احتمال بلوغ 5,000$/شهر بحلول اليوم 90:   ~50%
```

> **مقارنة صريحة:**
> - 5,000$ مرة واحدة في 50 يوماً — احتمال **20-25%**
> - 5,000$ **كل شهر** بحلول اليوم 90 — احتمال **~50%**
>
> الخطة تلاحق الأول لأنك طلبته، **وتبني الثاني لأنه الأصح**. ولا تعارض بينهما: نفس الأفعال تنتج الاثنين.
